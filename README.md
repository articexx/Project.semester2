# Бюджетный помощник:

Консольное мини приложение для учёта ежедневных расходов за месяц. 

# Функционал: 
1.  Добавление расходов
2. Сумма за период
3. День с максимальным расходом
4. Сортировка категорий по сумме
5. Алфавитный вывод категорий 
6. Отмена последней операции
7. Просмотр всех расходов
8. Выход из программы

# Структура проекта: 

budget-helper/
├── main.py          # точка входа, консольное меню, запуск всего кода
├── tracker.py       # основная логика: трекер, префиксные суммы, стек, сортировка
├── tree.py          # бинарное дерево поиска для хранения категорий
└── readme.md        # документация проекта

# Описание работы: 

Проект хранит ежедневные расходы в массиве из 30 элементов и параллельно строит массив 
префиксных сумм, что позволяет вычислять сумму за любой интервал дней за O(1) просто простым 
вычитанием двух чисел. Каждое добавление расхода сохраняется в стек, а при отмене последняя 
операция извлекается оттуда и все структуры данных откатываются назад. Категории хранятся 
в бинарном дереве поиска, которое обходом inorder выдаёт их в алфавитном порядке. Для сортировки 
по сумме трат вручную реализован алгоритм сортировки вставками. День с максимальным расходом 
находится линейным перебором всех 30 дней.
